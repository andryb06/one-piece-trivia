# One Piece Trivia

A multiple-choice quiz about the One Piece anime and manga. Answer the questions, see your score, and play again.

The game loads its questions from `events.json`. Each question has a prompt, answer choices, and a correct answer.

The published site is at https://andryb06.github.io/one-piece-trivia/.

## GitHub Pages deployment

This project is a static site and uses a GitHub Actions deployment workflow. To publish updates, make sure the repository's Pages settings use the `GitHub Actions` source, then push to the `main` branch.
